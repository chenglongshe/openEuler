# SR（System Requirement，系统需求）

---

### 【类型】

功能

### 【需求详情】

虚拟化节点代理作为代理组件，为系统提供统一的虚拟化基础设施管理能力，涵盖计算、网络和存储三大核心领域，构建了一体化的虚拟化资源管理解决方案。该组件负责在 xVirt 统一管理框架与虚拟资源管理之间建立通信桥梁，支持对主机资源进行统一管理与动态分配。具体功能要求包括：

1. **计算资源管理**
   - 支持虚拟机发放、虚拟机生命周期操作
   - 支持虚拟机快照管理

2. **网络资源管理**
   - 支持创建/删除/修改虚拟交换机实例和端口组配置
   - 实现 VLAN 隔离、流量控制等网络策略管理
   - 支持将虚拟机网络接口卡绑定到指定端口组

3. **存储资源管理**
   - 支持数据存储生命周期管理（创建/删除/扩容）
   - 支持存储容量监控

### 【约束】

1. **平台兼容性**：支持 x86_64 和 aarch64 架构的 FusionOS
2. **部署约束**：以 RPM 包形式交付，支持标准 Linux 包管理器安装和升级；依赖条件包括：Python、Libvirt、QEMU、Open vSwitch；需部署在宿主机节点，最小占用资源为 4 核心 CPU、8 GB 内存、100 GB 存储空间。

### 【范围】

该需求覆盖宿主机上所有运行的虚拟机实例及其相关的计算、网络和存储资源。

### 【验收标准（GIVEN‑WHEN‑THEN）】

> 以下验收标准均从**最终用户（虚拟化平台管理员）可执行、可观测**的角度编写。

**场景 1：支持虚拟机创建接口**

- GIVEN 系统正常运行，存储/网络资源充足
- WHEN 调用提供的一系列创建虚机的 API 接口发起创建虚拟机请求
- THEN 虚拟机创建成功，可查询到完整虚机信息和虚拟机进程信息

**场景 2：支持虚拟机删除接口**

- GIVEN 系统正常运行，主机环境虚机处于运行状态
- WHEN 调用提供的一系列删除虚拟机的 API 接口发起删除虚拟机请求
- THEN 虚拟机删除成功，主机上查询不到指定删除的虚拟机进程信息

**场景 3：网络配置变更接口**

- GIVEN 虚拟交换机已在节点部署，交换机列表参数合法
- WHEN 通过提供的一系列 API 发起修改端口组 VLAN 配置
- THEN 网络配置变更成功

**场景 4：存储创建/扩容/删除接口**

- GIVEN 系统存储正常
- WHEN 通过提供的一系列 API 发起创建存储资源并扩容和删除
- THEN 操作后容量值查询正确
