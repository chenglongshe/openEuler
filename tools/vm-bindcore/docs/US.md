# US（User Story，用户故事）

---

## US-01：虚拟机发放与生命周期管理

### 【US描述】
作为**虚拟化平台管理员**，我希望**通过 API 接口创建、启动、停止、重启和删除虚拟机**，以便**在宿主机上按需管理计算资源**。

### 【依赖】
- Libvirt、QEMU/KVM 虚拟化环境
- 存储和网络资源已就绪

### 【用户接口】
- 虚拟机创建 API
- 虚拟机删除 API
- 虚拟机生命周期操作 API（启动/停止/重启）
- 虚拟机信息查询 API

### 【验收准则】

> 以下验收标准从最终用户可执行、可观测角度编写。

**AC-US-01-01**：
- GIVEN 系统正常运行，存储和网络资源充足
- WHEN 管理员调用创建虚拟机 API，指定 CPU、内存、磁盘、网络等参数
- THEN 虚拟机创建成功；管理员通过 `virsh list --all` **可看到**新建虚拟机处于运行状态，通过 `ps aux | grep qemu` **可看到**对应的 QEMU 进程

**AC-US-01-02**：
- GIVEN 虚拟机处于运行状态
- WHEN 管理员调用删除虚拟机 API
- THEN 虚拟机删除成功；管理员通过 `virsh list --all` **看不到**该虚拟机，通过 `ps aux | grep qemu` **看不到**对应的 QEMU 进程

## US-02：虚拟机快照管理

### 【US描述】
作为**虚拟化平台管理员**，我希望**能够对虚拟机创建快照、查询快照列表并恢复到指定快照**，以便**在系统变更前保存状态，出现问题时快速回退**。

### 【依赖】
- US-01（虚拟机已创建并运行）
- 存储空间足够存放快照数据

### 【用户接口】
- 虚拟机快照创建 API
- 虚拟机快照列表查询 API
- 虚拟机快照恢复 API
- 虚拟机快照删除 API

### 【验收准则】

> 以下验收标准从最终用户可执行、可观测角度编写。

**AC-US-02-01**：
- GIVEN 虚拟机 vm1 处于运行状态
- WHEN 管理员调用快照创建 API 创建名为 `snap-01` 的快照
- THEN 快照创建成功；管理员通过 `virsh snapshot-list vm1` **可看到** `snap-01` 出现在快照列表中

**AC-US-02-02**：
- GIVEN 虚拟机 vm1 已有快照 `snap-01`，管理员在虚拟机内做了变更操作
- WHEN 管理员调用快照恢复 API 恢复到 `snap-01`
- THEN 恢复成功；管理员登录虚拟机 **可看到** 系统状态已回退到快照创建时的状态

## US-03：虚拟交换机与端口组管理

### 【US描述】
作为**虚拟化平台管理员**，我希望**通过 API 创建/删除/修改虚拟交换机和端口组，配置 VLAN 隔离策略**，以便**为虚拟机提供灵活的网络隔离与连通能力**。

### 【依赖】
- Open vSwitch 已安装并运行
- 物理网络端口已就绪

### 【用户接口】
- 虚拟交换机创建/删除 API
- 端口组创建/删除/修改 API
- VLAN 配置 API
- 虚拟机网卡绑定端口组 API

### 【验收准则】

> 以下验收标准从最终用户可执行、可观测角度编写。

**AC-US-03-01**：
- GIVEN Open vSwitch 正常运行
- WHEN 管理员调用 API 创建虚拟交换机 `vswitch-01` 并创建端口组 `pg-vlan100`（VLAN ID = 100）
- THEN 管理员通过 `ovs-vsctl show` **可看到** `vswitch-01` 已创建；通过查询接口 **可看到** 端口组 `pg-vlan100` 的 VLAN 配置为 100

**AC-US-03-02**：
- GIVEN 端口组 `pg-vlan100` 已存在，VLAN ID 为 100
- WHEN 管理员调用 API 将该端口组 VLAN ID 修改为 200
- THEN 修改成功；管理员通过查询接口 **可看到** 端口组 `pg-vlan100` 的 VLAN 配置已变更为 200

## US-04：存储资源生命周期管理

### 【US描述】
作为**虚拟化平台管理员**，我希望**通过 API 创建、扩容、删除数据存储并监控容量**，以便**按需为虚拟机提供充足的存储空间**。

### 【依赖】
- 宿主机存储后端（本地磁盘/SAN/NFS）已就绪

### 【用户接口】
- 数据存储创建 API
- 数据存储扩容 API
- 数据存储删除 API
- 存储容量查询 API

### 【验收准则】

> 以下验收标准从最终用户可执行、可观测角度编写。

**AC-US-04-01**：
- GIVEN 系统存储后端正常
- WHEN 管理员调用 API 创建 100 GB 的数据存储 `ds-01`
- THEN 创建成功；管理员通过容量查询 API **可看到** `ds-01` 的总容量为 100 GB

**AC-US-04-02**：
- GIVEN 数据存储 `ds-01` 容量为 100 GB
- WHEN 管理员调用扩容 API 将 `ds-01` 扩容到 200 GB，然后调用删除 API 删除 `ds-01`
- THEN 扩容后通过查询 API **可看到** 容量变为 200 GB；删除后通过查询 API **看不到** `ds-01`
